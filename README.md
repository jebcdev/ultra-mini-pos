# UltraMiniPOS 🛒⚡

**El sistema Punto de Venta (POS) MÁS PEQUEÑITO y ligero que existe**  
Hecho con ❤️ + PHP + Laravel + FilamentPHP en su versión más minimalista posible

## ¿Qué es UltraMiniPOS?

Un sistema POS **ultra compacto** diseñado para ser:

-   Muy ligero (pocas dependencias)
-   Fácil de instalar y entender
-   Ideal para tienditas, ferias, eventos, emprendedores o proyectos educativos
-   100% open source y listo para que lo adaptes a tu gusto
